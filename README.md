# 步步朝陽

朝陽科技大學校園概念導覽。由 scroll-world 技能的原始 scrub engine 改編，
不是自動播放影片，也不是可自由旋轉的即時 3D 模型。

## 體驗

- 向下捲動前進、向上捲動回遊；八站導覽與可拖曳的進度列。
- 8 段校園鏡頭 + 7 段以相鄰實際影格生成的連接鏡頭。
- 暫停狀態下按捲動位置更新 currentTime；Blob 載入、seek 合併、GOP 8。
- 專注看風景、靜態模式、系統 reduced-motion、手機上一站／下一站。
- 影片載入或解碼失敗時保留靜態景觀，不顯示空白播放器。

## 素材與限制

影片使用 Google Flow 的 Omni 1.1 Flash 生成；網站使用 720p 原生尺寸。
行政核心、鐘樓及總覽採用使用者指定的新鐘樓式行政大樓。
其他場景屬概念化微縮景觀，部分遠景仍有初始模型的建築配置。
非校方實測地圖、非實景照片；不能作為精確路線導航。
生成影片首尾可能有構圖偏移，連接鏡頭已做漸進式構圖配準與 8 影格淡接。
原始素材與本機處理/驗證報告保留在上層工作目錄，不隨網站發布。
部分起始影格保留參考海報文字；不宣稱整段幾何完全一致。
未建立另外的手機 beta 影片編碼，也未在實體 iOS 裝置測試。

## 開發

`npm install`、`npm run dev`（localhost:3000）。
`npx tsc --noEmit`、`npm run build`。
修改 `lib/journey.ts` 以更新八站文字、影片及排序。
`lib/scroll-world.js` 為可清理、可掛載的捲動鏡頭引擎。

所有校園畫面為使用者提供參考圖及本次生成素材；圖示使用 Lucide。
